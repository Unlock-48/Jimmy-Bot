# 🤖 Jimmy-Bot: ระบบจัดการไฟล์คลาวด์อัจฉริยะ (Interactive Cloud Storage Bot)

บอท Discord จัดการคัดแยกประเภทรูปภาพและเอกสารอัตโนมัติ ส่งตรงเข้าสู่คลัง Google Drive ส่วนตัว พร้อมเชื่อมต่อระบบความจำถาวรบนคลาวด์ด้วย Turso (SQLite) รองรับอินเตอร์เฟสปุ่มกดและการทำงานบนมือถือ 100%

## 📅 บันทึกความคืบหน้าและการเรียนรู้ (Developer Diary)

> *ใช้ส่วนนี้ในการจดบันทึกไดอารี่ อัปเดตความรู้ในแต่ละวัน เพื่อสร้างวินัยและสะสมกล่องเขียวบน GitHub 🚀*

### 🟢 Day 1 (11 มิ.ย. 2026) - สถาปัตยกรรม UI และระบบความปลอดภัย
- **สิ่งที่ทำสำเร็จ:**
  - ผูกท่อเชื่อมต่อ **Discord Bot + Groq Cloud AI + Turso DB + Google Drive API** ได้สำเร็จ
  - สลับระบบสิทธิ์เข้าใช้ Google API มาเป็นแบบ **OAuth2** เพื่อแก้ปัญหาโควตาเก็บข้อมูลส่วนตัว (Storage Quota)
  - ทำ **Modularization** แยกโค้ดออกเป็นชิ้น ๆ สร้างระบบจัดการหน้าบ้านไว้ที่ `src/fileUI.js` ทำให้โค้ดหลักคลีนและหล่อขึ้น
  - ออกแบบ UI แบบ **ปุ่มกด (Buttons)** และ **Dropdown Menu** ที่สามารถนิ้วจิ้มเลือก หรือพิมพ์เองบนหน้าจอมือถือได้แบบสวยงาม
  - อัปเกรดระบบ **Auto-Healing ดักจับ Error 404** หากเผลอลบโฟลเดอร์บนไดรฟ์จริง ระบบจะชุบชีวิตสร้างโฟลเดอร์ใหม่ผูกเข้า DB ให้ทันทีโดยที่บอทไม่ล่ม
  - เรียนรู้วิธีการทำ **Git Multi-Remote** เพื่อผลักโค้ด (Push) เก็บพอร์ตโฟลิโอขึ้น 2 บัญชีพร้อมกันอย่างปลอดภัย
- **ความรู้เทคนิคที่ได้รับ (Key Takeaways):**
  - ข้อจำกัดของ Discord Component: ตัวแปร `value` ใน Dropdown Menu จำกัดความยาว**ห้ามเกิน 100 ตัวอักษร** (วิธีแก้: ส่งไปแค่ ID โฟลเดอร์ตรง ๆ แทนก้อน JSON)
  - ความปลอดภัยระดับ Production: การจัดโครงสร้างโปรเจกต์และวางระบบยามเฝ้าประตูด้วย **`.gitignore`** เพื่อบล็อกไฟล์ลับ (`.env`, `token.json`) ไม่ให้หลุดสู่สาธารณะ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

| ส่วนของระบบ | เทคโนโลยีที่เลือกใช้ | รายละเอียดการทำงาน |
| :--- | :--- | :--- |
| **Runtime** | `Node.js (ES Modules)` | ขับเคลื่อนระบบหลังบ้านด้วย JavaScript สมัยใหม่ |
| **Interface** | `Discord.js v14` | สร้างแผงควบคุม UI ปุ่มกด และรับข้อความแบบ Real-time |
| **AI Brain** | `Groq Cloud API` | ขุมพลังโมเดล `llama-3.1-8b-instant` สรุปชื่อโฟลเดอร์ใน 0.5 วินาที |
| **Database** | `Turso Cloud` | ฐานข้อมูลคลาวด์ผูกบนเทคโนโลยี SQLite เพื่อจดจำพิกัดโฟลเดอร์ |
| **Storage** | `Google Drive API` | พื้นหลังคลังจัดเก็บไฟล์ส่วนตัว เชื่อมต่อตรงผ่าน Token สิทธิ์เข้าถึง |

## 📂 โครงสร้างระบบ (Project Modularity)

```text
simple-gemini-bot/
├── src/                    <-- โฟลเดอร์เก็บโมดูลย่อย (แยกสัดส่วนชัดเจน)
│   ├── database.js         # ระบบเชื่อมต่อและคีย์ข้อมูลลง Turso DB
│   ├── fileClassifier.js   # โมดูลวิเคราะห์ประเภทไฟล์เก่า
│   ├── fileHandler.js      # ดักจับและสกัดเอกสาร/รูปภาพที่ส่งเข้า Discord
│   ├── fileUI.js           # [Core] แผงปุ่มกดอินเตอร์เฟส และระบบ Auto-Healing 404
│   └── googleDrive.js      # ตัวจัดการ Stream อัปโหลดไฟล์ทะลุคลาวด์ Google
├── .env.example            # ไฟล์จำลองสำหรับตั้งค่าตัวแปรสิ่งแวดล้อม
├── .gitignore              # ยามเฝ้าประตูสั่งบล็อกกุญแจลับไม่ให้หลุดขึ้นอินเทอร์เน็ต
├── index.js                # [Main] จุดเริ่มรันระบบและตัวดักจับ Event แชท
└── package.json            # ไฟล์ระบุ Dependencies ทั่วทั้งโปรเจกต์

```

## 🔒 มาตรฐานความปลอดภัย (Secure by Design)

โปรเจกต์นี้ได้รับการพัฒนาภายใต้แนวคิด Security First โดยมีการแยกความลับ (Secrets) ออกจากซอร์สโค้ดอย่างเด็ดขาด ผ่านไฟล์ `.env` และมีการตั้งค่าไฟล์คัดกรอง `.gitignore` เพื่อสกัดกั้นไฟล์กุญแจส่วนตัวและโทเค็นการเข้าถึงข้อมูลระบบคลาวด์ทิ้งไว้ในเครื่อง Local เท่านั้น ทำให้โค้ดที่อยู่บนคลัง GitHub นี้ปลอดภัย 100% สามารถนำไปต่อยอดและแบ่งปันความรู้ต่อได้อย่างไร้กังวล

```
